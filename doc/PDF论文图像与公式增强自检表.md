# PDF 论文图像与公式增强自检表

每次启用 Paper V2、切换 Vision 模型或切换 MinerU 后，重新解析一份图表和公式都较多的 PDF，并记录结果。

## 配置前

- [ ] Paper 分块方法已选中，Token 为 550，重叠率为 10%。
- [ ] 已确认当前解析器是 DeepDOC 或已配置的 MinerU。
- [ ] 已记录 Vision 模型名称、服务地址和连接测试结果。
- [ ] 若需要公式文本，已确认 MinerU 模型可用且公式识别开关已开启。

## 图片增强

- [ ] `image_vision_enable` 已按预期启用或关闭。
- [ ] 启用且配置 Vision 模型时，任务出现 `Visual model detected` 状态。
- [ ] 未配置 Vision 模型时，任务明确显示“configure a default Vision model”，而不是静默成功。
- [ ] Vision 调用失败时，任务显示 `Visual model error`，原图和图注仍被保留。
- [ ] 至少抽查三张图：图号、图注、图内标签/坐标或结构说明能在图片块中检索。
- [ ] 图片上下文为 0 时，图块不混入无关正文；设置为 1 时，只有邻近说明被补充。

## 公式

- [ ] DeepDOC 路径下，公式不被误标为已识别的 LaTeX。
- [ ] 选择 MinerU 且启用公式识别后，抽查至少五个行内/行间公式。
- [ ] 公式编号、变量和单位没有被错误拼进相邻正文。
- [ ] MinerU 不可用或失败时，任务有明确错误，而不是生成空白公式块。

## 检索验收

- [ ] 用图号问题、图内参数问题、公式变量问题各测试一次。
- [ ] 每个问题的正确块进入 Top-5，且单独阅读足以定位页面内容。
- [ ] 图片 OCR 或公式乱码没有压过相关正文、图注和表格。
