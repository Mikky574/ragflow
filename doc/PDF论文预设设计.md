# PDF 论文预设设计

## 目标

为学术 PDF 提供可复用的 Paper 解析预设，使新文献继承经过验证的解析、分块和图表上下文参数。

## 预设：PDF 论文

| 项目 | 值 | 目的 |
| --- | --- | --- |
| 分块方法 | Paper | 按论文版面和章节处理 |
| 版面识别 | DeepDOC | 保留双栏、图表和位置 |
| 块大小 | 550 token | 平衡章节语义与检索粒度 |
| 重叠率 | 10% | 补足跨块上下文 |
| 父子块 | 关闭 | 避免一对一重复记录 |
| 表格上下文 | 1 | 保留相邻说明 |
| 图片上下文 | 0 | 避免图内 OCR 噪声扩散 |
| 图表关联窗口 | 1 | 限制关联范围 |

## 生效范围

知识库级配置是新上传文件的默认值；已有文件需重新解析才会使用新参数。

## 前端交互

在“知识库 → 配置 → Paper”提供“应用 PDF 论文预设”按钮，并暴露块大小、重叠率、表格上下文、图片上下文和图表关联窗口。保存后配置写入知识库。
