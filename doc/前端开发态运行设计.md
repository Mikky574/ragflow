# 前端开发态运行设计

## 目标

前端直接从 `web/` 源码运行，由 Vite 提供热更新；Docker 只保留 MySQL、Redis、MinIO、Elasticsearch 和 BGE-M3 等依赖服务。

## 运行方式

- 访问地址：`http://127.0.0.1:9222`
- 启动命令：`powershell -ExecutionPolicy Bypass -File .cache/dev/start-frontend-dev.ps1`
- API 代理：Vite 按 `API_PROXY_SCHEME=python` 将 `/api` 与 `/v1` 转发至 `127.0.0.1:9380`。
- 修改 `web/src/` 后由 Vite 热更新，无需重建镜像或重启容器。

## 服务边界

| 服务 | 运行方式 | 说明 |
| --- | --- | --- |
| 前端 | 本机 Vite 开发态 | 页面与配置改动立即可见 |
| Python API、任务执行器 | 本机开发态 | 使用当前源码与 GPU OCR 配置 |
| MySQL、Redis、MinIO、Elasticsearch、BGE-M3 | Docker | 保持基础依赖和 GPU 推理环境稳定 |

## PDF 论文预设

前端 Paper 配置页提供“应用 PDF 论文预设”。预设为 DeepDOC、550 token、10% 重叠、表格上下文 1、图片上下文 0、图表关联窗口 1，并关闭父子块。保存后写入知识库，后续上传的 PDF 使用该配置。
