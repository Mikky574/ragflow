# PDF 论文图像 OCR 自检表

每次调整 DeepDOC、OCR 模型或 Paper 分块后，使用至少一篇包含图号、图例、坐标轴和单位的论文重新解析并填写本表。

## 配置前

- [ ] 已选择 Paper 分块，Token 为 550，重叠率为 10%。
- [ ] 版面识别为 DeepDOC。
- [ ] 已记录测试论文、页码和代表性图片编号。
- [ ] 图片上下文为 0，表格上下文为 1。

## 图片 OCR 覆盖

- [ ] 每个抽查图片块保留原图或位置。
- [ ] 图号和图注可在图片块中检索。
- [ ] 图内至少一项文字进入图片块：坐标轴、图例、单位、曲线标签或结构标注。
- [ ] 查询图号、坐标轴名称和单位时，正确图片块进入 Top-5。
- [ ] 同一 OCR 行不会在图片块中重复出现。
- [ ] 图注有多个不同图号时，不会写入错误的图号关联。
- [ ] 图片 OCR 未混入无关页面正文、页眉或参考文献。

## OCR 质量

- [ ] 抽查至少三张图，记录漏识别和明显错字。
- [ ] 坐标轴密集数字、刻度和图例不会压过与问题相关的正文或图注。
- [ ] 需要检索的英文、中文、希腊字母和单位在当前 OCR 模型字符集内可识别。
- [ ] 图片未被识别为 `figure` 时，记录页码、区域和原始 PDF 截图。

## 公式边界

- [ ] DeepDOC 结果没有把公式 OCR 错称为 LaTeX。
- [ ] 公式检索需求单独记录，等待后续 MinerU 方案，不与图片 OCR 验收混为一项。
