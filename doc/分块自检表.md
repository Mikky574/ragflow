# 论文 PDF 分块自检表

每次修改解析或分块配置后，重新解析一份代表性文献，并逐项检查。未通过时记录具体页面、块序号和问题文本，再按“论文 PDF 分块设计”中的调参顺序处理。

标记约定：`[x]` 表示已实际核验通过；`[ ]` 表示未通过或尚未完成验证。当前文献的核验结论见文末。

## 解析前

- [x] 明确检索任务：事实问答、方法/参数检索、图表问答，或全文定位。
- [x] 确认 PDF 是否是双栏、扫描件、图表密集型或含大量公式。
- [x] 保存当前配置和当前块数，作为回滚比较基线。

## 文本覆盖

- [x] 标题在单独或清晰的首块中。
- [x] 作者、单位、邮箱等前置信息可被检索到，未混入正文中段。
- [x] 摘要完整，且没有被分到多个无语义关联的小块。
- [x] 每个主要章节至少有一个正文块。
- [x] 结论和参考文献没有混在同一个主要正文块中。

## 阅读顺序与语义

- [ ] 抽查两页双栏正文，没有左右栏交错成一句话。
- [ ] 每个正文块只讨论一个主要主题。
- [ ] 方法、条件、数值和单位没有被拆得无法理解。
- [ ] 块的开头有主语、章节名或足以理解指代的上下文。
- [x] 页眉、页脚、版权信息没有成为主要检索内容。

## 图表

- [ ] 图注可单独检索，例如查询 `Fig. 2` 能命中相应图注。
- [x] 图表块没有把大量坐标轴、图例或乱码当成正文。
- [ ] 正文引用、图注和图片分离时，确认图注仍保留图号与足够说明。
- [ ] 图片上下文设为 0 时，检索结果不会优先返回图内 OCR。
- [x] 表格上下文设为 1 时，表格的标题或邻近解释仍可读。

## 大小与重复

- [x] 正文块多数在目标范围内：200–550 token。
- [x] 不存在大量少于约 80 token 的纯正文碎块。
- [x] 不存在大量超过 600 token 且混合多个主题的正文块。
- [x] 重叠内容只出现在块边界附近，不连续重复多次。
- [x] 启用父子分块时，确认页面总数包含母块和子块；审阅时按关联关系判断，不把它误认为重复解析。

## 检索验收

用实际问题测试，并检查前 3–5 条结果。

- [ ] 论文的目标、方法、关键参数和结论各准备至少一个问题。
- [ ] 正确块进入前 3–5 条结果。
- [ ] 命中块单独阅读能回答问题，或明确显示需要的相邻上下文。
- [ ] 无关图内 OCR、参考文献和页眉没有压过正文结果。
- [ ] 若启用父子分块，验证子块命中后返回的母块没有引入不相关章节。
