# 人工标注目录

`candidates/` 是 DeepDOC 自动裁出的候选图片区。人工确认后，**复制**图片到 `使用/` 或 `不使用/`；文件名保持不变，便于和 `candidates/manifest.jsonl` 中的 `id` 对应。

## 使用

这些图片保留为知识库检索内容，也作为分类模型的正样本。类别按图片表达的信息类型划分：

| 中文目录 | 稳定类别标识 | 放入条件 |
| --- | --- | --- |
| `使用/科学图表/` | `scientific_plot` | 曲线图、散点图、柱状图、统计图 |
| `使用/模型与结构图/` | `model_or_structure_diagram` | 模型架构、方法流程、系统框图、机理图、电路原理图 |
| `使用/器件与实物照片/` | `device_photo` | 研究对象的器件、装置、实物照片 |
| `使用/测量与仿真图/` | `measurement_image` | 显微图、热图、仿真结果、测试图 |
| `使用/软件截图/` | `software_screenshot` | 软件、网页、终端截图，且含有任务信息 |
| `使用/表格/` | `table` | 表格或表格截图 |
| `使用/公式/` | `equation` | 单公式或公式组；不含纯正文中的行内公式 |

“模型与结构图”不表示泛泛的“科学图片”。它只指论文用来解释**方法、模型、系统、机理或电路结构**的图；例如神经网络架构图、实验流程图、Class-F PA 电路原理图。它与“科学图表”的曲线/统计结果，以及“测量与仿真图”的显微、热图和仿真输出分开标注。

## 不使用

`不使用/` 是一个统一负类：所有不应进入检索或不属于以上有效类别的候选图片都直接复制到这里，不再按徽标、图标、装饰等细分。训练时其稳定类别标识为 `unused`。

不再设置“待复核”目录。尚未判断的候选图片继续留在 `candidates/`；确认后再复制到上述目录。不要重命名或删除 `candidates/` 下的原始文件，其 JSONL 清单会保留 OCR、页码与坐标。
