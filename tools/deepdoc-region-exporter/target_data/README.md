# 人工标注目录

`candidates/` 是 DeepDOC 自动裁出的候选图片区。人工确认后，**复制**图片到 `使用/` 或 `不使用/` 的一个中文子目录；文件名保持不变，便于和 `candidates/manifest.jsonl` 中的 `id` 对应。

## 使用

这些图片保留为知识库检索内容，也作为分类模型的正样本。

| 中文目录 | 稳定类别标识 | 放入条件 |
| --- | --- | --- |
| `使用/科学图表/` | `scientific_plot` | 曲线图、散点图、柱状图、统计图 |
| `使用/科学示意图/` | `scientific_schematic` | 模型结构图、算法流程图、电路图 |
| `使用/器件与实物照片/` | `device_photo` | 研究对象的器件、装置、实物照片 |
| `使用/测量与仿真图/` | `measurement_image` | 显微图、热图、仿真结果、测试图 |
| `使用/软件截图/` | `software_screenshot` | 软件、网页、终端截图，且含有任务信息 |
| `使用/表格/` | `table` | 表格或表格截图 |
| `使用/公式/` | `equation` | 单公式或公式组；不含纯正文中的行内公式 |

## 不使用

这些图片不进入知识库检索，但可作为分类模型的负样本。

| 中文目录 | 稳定类别标识 | 放入条件 |
| --- | --- | --- |
| `不使用/徽标/` | `logo` | 品牌、机构、会议标志 |
| `不使用/界面图标/` | `ui_icon` | 图标、按钮、箭头、项目符号 |
| `不使用/装饰/` | `decorative` | 背景、分隔线、无信息装饰 |
| `不使用/无关图片/` | `irrelevant_image` | 与文档研究内容无关的普通图片、素材图、作者头像、纯装饰插图 |

不再设置“待复核”目录。它不是一个可训练的稳定类别：不确定的图片继续留在 `candidates/`，等人工确认后再复制到上述目录。不要重命名或删除 `candidates/` 下的原始文件；其 JSONL 清单会保留 OCR、页码与坐标。
